# Organizador de Declaração de Imposto de Renda

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte da **Atividade 2 da DIO** e consiste em uma planilha para auxiliar na organização das informações necessárias para a declaração do Imposto de Renda.

A proposta é centralizar dados pessoais, informes de rendimentos bancários e movimentações financeiras em uma estrutura organizada, facilitando a conferência das informações e a preparação dos dados antes do preenchimento da declaração.

> **Observação:** esta planilha é um organizador de informações e não substitui o programa oficial da Receita Federal nem a orientação de um profissional contábil.

## 🎯 Objetivo

Criar uma ferramenta prática para:

- organizar os dados do titular;
- registrar informações dos bancos e respectivos informes de rendimentos;
- controlar documentos e anexos utilizados como comprovantes;
- registrar entradas financeiras mês a mês;
- facilitar a conferência e consolidação das informações;
- reduzir o risco de esquecer dados ou documentos importantes.

## 📊 Estrutura da planilha

O arquivo está dividido em quatro abas principais:

### 1. TITULAR

Área destinada ao cadastro das informações pessoais do contribuinte.

Entre os dados disponíveis estão:

- Nome;
- CPF;
- Data de nascimento;
- Título de eleitor;
- Cônjuge;
- Endereço;
- CEP;
- Telefone e celular;
- E-mail;
- Alterações em relação à declaração anterior;
- Informação sobre dependência do cônjuge;
- Residência no exterior.

### 2. INFORMES

Área para organização dos informes de rendimentos bancários.

É possível registrar:

- banco utilizado;
- valor atual informado;
- arquivo ou documento relacionado ao informe;
- informações de até três instituições financeiras no modelo atual.

A aba também possui um campo de **totalização automática** dos valores registrados.

### 3. NOTAS

Área destinada ao registro das entradas financeiras mês a mês.

A estrutura permite organizar:

- data;
- categoria;
- valor.

Essa organização facilita a conferência das movimentações e a identificação das informações que precisam ser consideradas na declaração.

### 4. TABELAS

Aba de apoio utilizada para disponibilizar listas de referência, principalmente instituições bancárias.

Essas informações auxiliam no preenchimento padronizado dos campos da planilha.

## ⚙️ Recursos utilizados

O projeto demonstra a aplicação de recursos do Excel, como:

- organização de dados em diferentes abas;
- listas de referência;
- campos estruturados para preenchimento;
- validação de dados;
- fórmulas para totalização automática;
- organização de documentos e comprovantes;
- separação entre dados de entrada e tabelas auxiliares.

## 📝 Como utilizar

1. Abra a planilha.
2. Na aba **TITULAR**, preencha os dados pessoais do contribuinte.
3. Na aba **INFORMES**, informe os bancos utilizados e os valores apresentados nos respectivos documentos.
4. Registre ou associe os comprovantes e informes correspondentes.
5. Na aba **NOTAS**, lance as entradas financeiras conforme os documentos disponíveis.
6. Utilize a aba **TABELAS** como referência para os campos padronizados.
7. Revise todos os dados e documentos antes de utilizar as informações para a declaração oficial.

## 🔎 Boas práticas

Para manter a organização:

- utilize os dados exatamente como aparecem nos documentos oficiais;
- mantenha os comprovantes arquivados;
- confira CPF, datas e valores antes de finalizar;
- evite deixar campos obrigatórios sem preenchimento;
- revise os lançamentos antes de transferi-los para a declaração oficial;
- mantenha uma cópia da planilha preenchida e dos documentos utilizados.

## 📚 Aprendizados da atividade

A atividade permite praticar conceitos importantes de organização e tratamento de dados no Excel, especialmente:

- estruturação de informações;
- criação de planilhas funcionais;
- uso de fórmulas;
- validação e padronização de dados;
- organização de informações financeiras;
- criação de ferramentas para facilitar processos manuais.
